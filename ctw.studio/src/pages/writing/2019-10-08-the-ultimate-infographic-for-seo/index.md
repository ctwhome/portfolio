## Modern web presence

Infographic presents modern web presence as equal balance between website communication and helping people discover site. Website half lists desirable interface design, recognizable brand, micro-interactions, context awareness, guided transitions, familiar patterns, affordance, accessibility, responsive design, and page-loading time. SEO half calls for human-centered content, clear answers to people’s questions, shareable value, keyword research, alt text, redirects, useful 404 pages, careful subdomain use, and awareness that popular trends can be harder to rank for.

Its summary: make your content amazing.

## Optimization checklist

1. Write for people, not search engines.
2. Answer people’s questions clearly and helpfully; artwork suggests concise titles and descriptions.
3. Structure content with headings, subheadings, and paragraphs.
4. Redirect old content with permanent redirects.
5. Generate an XML sitemap.
6. Use relevant tags and keywords.
7. Optimize URLs, metadata titles, and descriptions.
8. Build a helpful 404 page that explains error and offers a way forward.
9. Mark canonical URLs.
10. Measure site behavior.
11. Add useful alt text to images.

For keyword research, infographic recommends checking real search behavior before writing, then using relevant terms naturally in titles, content, headers, metadata, URLs, and image alt text. It also recommends keeping important pages near top of information hierarchy, collecting user reviews, treating subdomains as separate sites for search purposes, linking related content, and checking every link, image, style, tag, and filename before publication.
